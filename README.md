# Feshven Bags

სრულიად სტატიკური ონლაინ-მაღაზია. გახსენი `index.html` ბრაუზერში.

## ფუნქციები

- პროდუქტის ძიება, კატეგორიები და დეტალები
- კალათა, რომელიც ინახება იმავე ბრაუზერში
- რეგისტრაცია და შესვლა
- შეკვეთის გაფორმება და შეკვეთების ისტორია პროფილში

## მნიშვნელოვანი შენიშვნა

ეს ვერსია არ იყენებს სერვერს ან მონაცემთა ბაზას. ანგარიშები, პაროლები და შეკვეთები ინახება მხოლოდ იმ მოწყობილობის ბრაუზერში (`localStorage`). რეალური ონლაინ გადახდებისთვის, სხვადასხვა მოწყობილობაზე წვდომისთვის ან უსაფრთხო მომხმარებლის ანგარიშებისთვის საჭიროა backend/API და გადახდის პროვაიდერი.
